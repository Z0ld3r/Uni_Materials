Javascript 2. alkalom: DOM alapok, egyszerű eseménykezelés

Egyszerű gombra kattintós feladat
- HTML-elemek elérése querySelector()-ral
- input értékének beolvasása, kiírás innerHTML-lel
- otuput érték kiírása value-val
- kattintási esemény kezelése addEventListener()-rel

Kör kerülete feladat
- beolvasás → ellenőrzés → feldolgozás → kiírás
- parseFloat(), isNaN()
- hibás input jelzése classList.toggle()-lel
- return használata
- külön számoló függvény

DOM és JS tömbfüggvények – korábbi ZH-feladat összetettebb adatszerkezettel
- forEach, filter, some, find, reduce, map
- objektumok és tulajdonságaik elérése
- számlálás, eldöntés, kiválasztás, kiválogatás, összegzés
- ternary operátor, Math.round(), endsWith()
